1. Introduction to OOP

📚 What is OOP?

Object-Oriented Programming (OOP) is a programming paradigm that organizes code around objects rather than functions and logic. It models real-world entities as objects with properties (attributes) and behaviors (methods).

Why OOP?

  • Code Reusability: Write once, use many times
  • Better Organization: Logical grouping of related data and functions
  • Easier Maintenance: Changes in one place affect all instances
  • Real-World Modeling: Represents real entities naturally
  • Encapsulation: Data hiding and protection

💻 Example: Procedural vs OOP

# Without OOP (Procedural Approach)
car1_brand = "Toyota"
car1_model = "Camry"
car1_year = 2020

def start_car1():
    print(f"{car1_brand} {car1_model} is starting")

start_car1()

# Problem: What if you need 10 cars? 
# You'd need 30 variables and 10 functions!

# With OOP (Object-Oriented Approach)
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year
    
    def start(self):
        print(f"{self.brand} {self.model} is starting")

# Create multiple cars easily
car1 = Car("Toyota", "Camry", 2020)
car2 = Car("Honda", "Civic", 2021)
car3 = Car("Ford", "Mustang", 2022)

car1.start()  # Toyota Camry is starting
car2.start()  # Honda Civic is starting
car3.start()  # Ford Mustang is starting

2. Classes and Objects

📚 Core Concepts

  • Class: A blueprint/template for creating objects
  • Object: An instance of a class with actual values
  • Attributes: Variables that belong to a class/object
  • Methods: Functions that belong to a class
  • __init__: Constructor method (initializer)
  • self: Reference to the current instance

💻 Complete Class Example

class Student:
    # Class attribute (shared by all instances)
    school_name = "Python High School"
    
    def __init__(self, name, age, grade):
        # Instance attributes (unique to each object)
        self.name = name
        self.age = age
        self.grade = grade
        self.subjects = []
    
    # Instance method
    def introduce(self):
        return f"Hi, I'm {self.name}, {self.age} years old, in grade {self.grade}"
    
    # Method with parameters
    def study(self, subject):
        return f"{self.name} is studying {subject}"
    
    def add_subject(self, subject):
        self.subjects.append(subject)
        print(f"{self.name} enrolled in {subject}")
    
    def display_info(self):
        print(f"Student: {self.name}")
        print(f"Age: {self.age}")
        print(f"Grade: {self.grade}")
        print(f"School: {Student.school_name}")
        print(f"Subjects: {', '.join(self.subjects) if self.subjects else 'None'}")

# Creating objects (instances)
student1 = Student("Alice", 15, 10)
student2 = Student("Bob", 16, 11)

# Using methods
print(student1.introduce())
print(student2.study("Mathematics"))

student1.add_subject("Math")
student1.add_subject("Science")
student1.display_info()

# Output:
# Hi, I'm Alice, 15 years old, in grade 10
# Bob is studying Mathematics
# Alice enrolled in Math
# Alice enrolled in Science
# Student: Alice
# Age: 15
# Grade: 10
# School: Python High School
# Subjects: Math, Science

3. Understanding self in Detail

📚 What is self?

self is a reference to the current instance of a class. It's how an object refers to itself and accesses its own attributes and methods.

Key Points:

  • NOT a keyword (unlike this in Java/C++)
  • Just a naming convention (you could use any name, but DON'T!)
  • First parameter of instance methods
  • Python automatically passes it when you call methods
  • Each object has its own self pointing to itself

💻 self in Action

class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner      # self.owner belongs to THIS object
        self.balance = balance  # self.balance belongs to THIS object
        print(f"Account created for {self.owner}")
    
    def deposit(self, amount):
        self.balance += amount  # Modify THIS object's balance
        print(f"{self.owner}'s new balance: ${self.balance}")
    
    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            print(f"{self.owner} withdrew ${amount}")
        else:
            print(f"{self.owner}: Insufficient funds!")
    
    def display_info(self):
        print(f"Owner: {self.owner}, Balance: ${self.balance}")

# Create two separate accounts
account1 = BankAccount("Alice", 1000)
account2 = BankAccount("Bob", 500)

# Each object maintains its own data
account1.deposit(200)    # Alice's balance becomes 1200
account2.deposit(100)    # Bob's balance becomes 600

account1.display_info()  # Owner: Alice, Balance: $1200
account2.display_info()  # Owner: Bob, Balance: $600

# They don't interfere with each other!
account1.withdraw(500)   # Alice's balance becomes 700
account2.display_info()  # Bob's balance is still 600

🎯 How Python Handles self

When you write account1.deposit(200), Python internally converts it to:

BankAccount.deposit(account1, 200)

So self is automatically set to account1!

⚠️ Common Mistakes with self

  1. Forgetting self parameter: 
    # ❌ Wrong
def display():  # Missing self
    print(self.name)  # Error!

# ✅ Correct
def display(self):
    print(self.name)
  2. Not using self for attributes: 
    # ❌ Wrong
def __init__(self, name):
    name = name  # Just a local variable!

# ✅ Correct
def __init__(self, name):
    self.name = name  # Instance attribute

4. The Four Pillars of OOP

4.1 Encapsulation

📚 Encapsulation Concept

Bundling data and methods together, and restricting direct access to some components.

Access Modifiers in Python:

  • Public: Accessible everywhere (default) - self.attribute
  • Protected: Prefix with _ (convention) - self._attribute
  • Private: Prefix with __ (name mangling) - self.__attribute

💻 Encapsulation Example

class BankAccount:
    def __init__(self, account_number, balance):
        self.account_number = account_number  # Public
        self._bank_name = "Python Bank"      # Protected
        self.__balance = balance             # Private
    
    # Getter method
    def get_balance(self):
        return self.__balance
    
    # Setter method with validation
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return f"Deposited ${amount}. New balance: ${self.__balance}"
        return "Invalid amount"
    
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            return f"Withdrew ${amount}. Remaining: ${self.__balance}"
        return "Insufficient funds or invalid amount"

account = BankAccount("123456", 1000)
print(account.get_balance())  # 1000
print(account.deposit(500))   # Deposited $500. New balance: $1500

# Direct access to private attribute won't work
# print(account.__balance)    # AttributeError

# Can access public and protected
print(account.account_number)  # 123456
print(account._bank_name)      # Python Bank (but shouldn't!)

4.2 Inheritance

📚 Inheritance Concept

A mechanism where a new class (child/derived) inherits properties and methods from an existing class (parent/base).

Types of Inheritance:

  • Single Inheritance: Child inherits from one parent
  • Multiple Inheritance: Child inherits from multiple parents
  • Multilevel Inheritance: Chain of inheritance (A → B → C)
  • Hierarchical Inheritance: Multiple children from one parent
  • Hybrid Inheritance: Combination of above types

💻 Single Inheritance Example

class Animal:
    def __init__(self, name, species):
        self.name = name
        self.species = species
    
    def make_sound(self):
        return "Some generic sound"
    
    def info(self):
        return f"{self.name} is a {self.species}"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name, "Dog")  # Call parent constructor
        self.breed = breed
    
    # Method overriding
    def make_sound(self):
        return "Woof! Woof!"
    
    # Additional method
    def fetch(self):
        return f"{self.name} is fetching the ball"

class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name, "Cat")
        self.color = color
    
    def make_sound(self):
        return "Meow!"

# Usage
dog = Dog("Buddy", "Golden Retriever")
print(dog.info())           # Inherited method: Buddy is a Dog
print(dog.make_sound())     # Overridden method: Woof! Woof!
print(dog.fetch())          # New method: Buddy is fetching the ball

cat = Cat("Whiskers", "Orange")
print(cat.info())           # Whiskers is a Cat
print(cat.make_sound())     # Meow!

💻 Multiple Inheritance Example

class Flyable:
    def fly(self):
        return "Flying high in the sky! ✈️"

class Swimmable:
    def swim(self):
        return "Swimming gracefully! 🏊"

class Duck(Animal, Flyable, Swimmable):
    def __init__(self, name):
        super().__init__(name, "Duck")
    
    def make_sound(self):
        return "Quack! Quack!"

# Duck inherits from Animal, Flyable, and Swimmable
duck = Duck("Donald")
print(duck.make_sound())  # Quack! Quack!
print(duck.fly())         # Flying high in the sky! ✈️
print(duck.swim())        # Swimming gracefully! 🏊
print(duck.info())        # Donald is a Duck

4.3 Polymorphism

📚 Polymorphism Concept

"Many forms" - the ability of objects to take multiple forms. Same method name behaves differently in different classes.

Types:

  • Method Overriding: Child class redefines parent method
  • Method Overloading: Same method, different parameters (Python uses default args)
  • Operator Overloading: Define behavior for operators (+, -, *, etc.)

💻 Method Overriding (Polymorphism)

class Shape:
    def area(self):
        pass
    
    def perimeter(self):
        pass

class Rectangle(Shape):
    def __init__(self, length, width):
        self.length = length
        self.width = width
    
    def area(self):
        return self.length * self.width
    
    def perimeter(self):
        return 2 * (self.length + self.width)

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14159 * self.radius ** 2
    
    def perimeter(self):
        return 2 * 3.14159 * self.radius

# Polymorphism in action - same method, different behavior
shapes = [Rectangle(5, 3), Circle(4), Rectangle(7, 2)]

for shape in shapes:
    print(f"Area: {shape.area():.2f}, Perimeter: {shape.perimeter():.2f}")

# Output:
# Area: 15.00, Perimeter: 16.00
# Area: 50.27, Perimeter: 25.13
# Area: 14.00, Perimeter: 18.00

💻 Operator Overloading

class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    def __sub__(self, other):
        return Vector(self.x - other.x, self.y - other.y)
    
    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)
    
    def __str__(self):
        return f"Vector({self.x}, {self.y})"
    
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

v1 = Vector(2, 3)
v2 = Vector(4, 5)

v3 = v1 + v2  # Uses __add__
print(v3)     # Vector(6, 8)

v4 = v1 * 3   # Uses __mul__
print(v4)     # Vector(6, 9)

print(v1 == v2)  # Uses __eq__ - False

4.4 Abstraction

📚 Abstraction Concept

Hiding complex implementation details and showing only essential features. Uses abstract classes and interfaces.

Abstract Class: A class that cannot be instantiated and may contain abstract methods that must be implemented by subclasses.

💻 Abstract Base Class Example

from abc import ABC, abstractmethod

class PaymentProcessor(ABC):
    @abstractmethod
    def process_payment(self, amount):
        """Must be implemented by subclasses"""
        pass
    
    @abstractmethod
    def refund(self, transaction_id):
        """Must be implemented by subclasses"""
        pass
    
    # Concrete method (can be used by all subclasses)
    def validate_amount(self, amount):
        return amount > 0

class StripePayment(PaymentProcessor):
    def process_payment(self, amount):
        if self.validate_amount(amount):
            return f"Processing ${amount} via Stripe"
        return "Invalid amount"
    
    def refund(self, transaction_id):
        return f"Refunding transaction {transaction_id} via Stripe"

class PayPalPayment(PaymentProcessor):
    def process_payment(self, amount):
        if self.validate_amount(amount):
            return f"Processing ${amount} via PayPal"
        return "Invalid amount"
    
    def refund(self, transaction_id):
        return f"Refunding transaction {transaction_id} via PayPal"

# Cannot instantiate abstract class
# payment = PaymentProcessor()  # TypeError!

# Can instantiate concrete classes
stripe = StripePayment()
print(stripe.process_payment(100))  # Processing $100 via Stripe

paypal = PayPalPayment()
print(paypal.process_payment(50))   # Processing $50 via PayPal

5. Advanced OOP Concepts

5.1 Class Methods and Static Methods

📚 Method Types

  • Instance Method: Works with instance (uses self)
  • Class Method: Works with class (uses cls, decorator @classmethod)
  • Static Method: Independent utility (no self or cls, decorator @staticmethod)

💻 All Method Types Example

class Employee:
    company_name = "TechCorp"
    employee_count = 0
    
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
        Employee.employee_count += 1
    
    # Instance method (uses self)
    def display_info(self):
        return f"{self.name} earns ${self.salary}"
    
    # Class method (uses cls)
    @classmethod
    def change_company_name(cls, new_name):
        cls.company_name = new_name
    
    @classmethod
    def from_string(cls, emp_string):
        # Alternative constructor
        name, salary = emp_string.split('-')
        return cls(name, int(salary))
    
    # Static method (no self or cls)
    @staticmethod
    def is_workday(day):
        return day not in ['Saturday', 'Sunday']
    
    @staticmethod
    def calculate_tax(salary):
        return salary * 0.2

# Instance method
emp1 = Employee("Alice", 50000)
print(emp1.display_info())  # Alice earns $50000

# Class method
Employee.change_company_name("NewTech")
print(Employee.company_name)  # NewTech

# Alternative constructor using class method
emp2 = Employee.from_string("Bob-60000")
print(emp2.display_info())  # Bob earns $60000

# Static method
print(Employee.is_workday("Monday"))  # True
print(Employee.calculate_tax(50000))  # 10000.0

5.2 Property Decorators

📚 Properties

Pythonic way to use getters and setters using @property, @setter, @deleter decorators.

💻 Using Properties

class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius
    
    @property
    def celsius(self):
        """Getter for celsius"""
        return self._celsius
    
    @celsius.setter
    def celsius(self, value):
        """Setter for celsius with validation"""
        if value < -273.15:
            raise ValueError("Temperature below absolute zero!")
        self._celsius = value
    
    @property
    def fahrenheit(self):
        """Computed property - converts celsius to fahrenheit"""
        return (self._celsius * 9/5) + 32
    
    @fahrenheit.setter
    def fahrenheit(self, value):
        """Set temperature using fahrenheit"""
        self.celsius = (value - 32) * 5/9
    
    @property
    def kelvin(self):
        """Computed property - converts celsius to kelvin"""
        return self._celsius + 273.15

# Usage - looks like attributes but uses methods!
temp = Temperature(25)
print(temp.celsius)      # 25 (uses getter)
print(temp.fahrenheit)   # 77.0 (computed)
print(temp.kelvin)       # 298.15 (computed)

temp.fahrenheit = 100    # Uses setter
print(temp.celsius)      # 37.77... (automatically updated)

# Validation works
try:
    temp.celsius = -300  # Below absolute zero
except ValueError as e:
    print(f"Error: {e}")  # Error: Temperature below absolute zero!

5.3 Composition vs Inheritance

📚 When to Use What

  • Inheritance: "is-a" relationship (Dog is-a Animal)
  • Composition: "has-a" relationship (Car has-a Engine)

Rule of Thumb: Favor composition over inheritance when possible!

💻 Composition Example

class Engine:
    def __init__(self, horsepower):
        self.horsepower = horsepower
    
    def start(self):
        return "Engine started"
    
    def stop(self):
        return "Engine stopped"

class Wheels:
    def __init__(self, count):
        self.count = count
    
    def rotate(self):
        return f"{self.count} wheels rotating"

class Car:
    def __init__(self, brand, horsepower, wheel_count):
        self.brand = brand
        self.engine = Engine(horsepower)  # Composition - Car HAS-A Engine
        self.wheels = Wheels(wheel_count)  # Composition - Car HAS-A Wheels
    
    def start(self):
        return f"{self.brand}: {self.engine.start()}, {self.wheels.rotate()}"
    
    def stop(self):
        return f"{self.brand}: {self.engine.stop()}"

car = Car("Toyota", 200, 4)
print(car.start())  # Toyota: Engine started, 4 wheels rotating
print(car.stop())   # Toyota: Engine stopped

6. Magic Methods (Dunder Methods)

📚 Common Magic Methods

Method Purpose Example
__init__(self, ...) Constructor obj = MyClass()
__str__(self) String representation (for print) print(obj)
__repr__(self) Official representation repr(obj)
__len__(self) Length len(obj)
__add__(self, other) Addition (+) obj1 + obj2
__sub__(self, other) Subtraction (-) obj1 - obj2
__mul__(self, other) Multiplication (*) obj1 * obj2
__eq__(self, other) Equality (==) obj1 == obj2
__lt__(self, other) Less than (<) obj1 < obj2
__getitem__(self, key) Indexing obj[key]

💻 Magic Methods in Action

class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages
    
    def __str__(self):
        """For print() - user-friendly"""
        return f"'{self.title}' ({self.pages} pages)"
    
    def __repr__(self):
        """For debugging - unambiguous"""
        return f"Book(title='{self.title}', pages={self.pages})"
    
    def __len__(self):
        """For len()"""
        return self.pages
    
    def __lt__(self, other):
        """For < comparison"""
        return self.pages < other.pages
    
    def __add__(self, other):
        """For + operator"""
        return Book(f"{self.title} & {other.title}", 
                   self.pages + other.pages)
    
    def __eq__(self, other):
        """For == comparison"""
        return self.title == other.title and self.pages == other.pages

book1 = Book("Python Basics", 300)
book2 = Book("Advanced Python", 450)

print(book1)              # Uses __str__: 'Python Basics' (300 pages)
print(repr(book1))        # Uses __repr__: Book(title='Python Basics', pages=300)
print(len(book1))         # Uses __len__: 300
print(book1 < book2)      # Uses __lt__: True
combined = book1 + book2  # Uses __add__
print(combined)           # 'Python Basics & Advanced Python' (750 pages)

7. Design Patterns

7.1 Singleton Pattern

📚 Singleton Pattern

Ensures a class has only one instance and provides a global point of access to it.

💻 Singleton Implementation

class DatabaseConnection:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.connection = "Database Connected"
        return cls._instance
    
    def query(self, sql):
        return f"Executing: {sql}"

# Create multiple "instances"
db1 = DatabaseConnection()
db2 = DatabaseConnection()

print(db1 is db2)  # True - same instance!
print(db1.query("SELECT * FROM users"))
print(db2.query("SELECT * FROM products"))  # Same connection

7.2 Factory Pattern

📚 Factory Pattern

Creates objects without specifying the exact class to create.

💻 Factory Implementation

class Dog:
    def speak(self):
        return "Woof!"

class Cat:
    def speak(self):
        return "Meow!"

class Bird:
    def speak(self):
        return "Tweet!"

class AnimalFactory:
    @staticmethod
    def create_animal(animal_type):
        if animal_type == "dog":
            return Dog()
        elif animal_type == "cat":
            return Cat()
        elif animal_type == "bird":
            return Bird()
        else:
            raise ValueError(f"Unknown animal type: {animal_type}")

# Use factory to create animals
animal1 = AnimalFactory.create_animal("dog")
animal2 = AnimalFactory.create_animal("cat")
animal3 = AnimalFactory.create_animal("bird")

print(animal1.speak())  # Woof!
print(animal2.speak())  # Meow!
print(animal3.speak())  # Tweet!

8.1 Library Management System

💻 Complete Library System

from datetime import datetime, timedelta

class Book:
    def __init__(self, isbn, title, author, copies):
        self.isbn = isbn
        self.title = title
        self.author = author
        self.total_copies = copies
        self.available_copies = copies
    
    def __str__(self):
        return f"{self.title} by {self.author} (ISBN: {self.isbn})"

class Member:
    def __init__(self, member_id, name, email):
        self.member_id = member_id
        self.name = name
        self.email = email
        self.borrowed_books = []
    
    def can_borrow(self):
        return len(self.borrowed_books) < 3

class Transaction:
    def __init__(self, book, member):
        self.book = book
        self.member = member
        self.borrow_date = datetime.now()
        self.due_date = self.borrow_date + timedelta(days=14)
        self.return_date = None
    
    def calculate_fine(self):
        if self.return_date and self.return_date > self.due_date:
            days_late = (self.return_date - self.due_date).days
            return days_late * 1  # $1 per day
        return 0

class Library:
    def __init__(self, name):
        self.name = name
        self.books = {}
        self.members = {}
        self.transactions = []
    
    def add_book(self, book):
        self.books[book.isbn] = book
        print(f"Added: {book}")
    
    def register_member(self, member):
        self.members[member.member_id] = member
        print(f"Registered: {member.name}")
    
    def borrow_book(self, isbn, member_id):
        book = self.books.get(isbn)
        member = self.members.get(member_id)
        
        if not book or not member:
            return "Book or member not found"
        
        if book.available_copies == 0:
            return "No copies available"
        
        if not member.can_borrow():
            return "Member has reached borrowing limit (3 books)"
        
        book.available_copies -= 1
        transaction = Transaction(book, member)
        self.transactions.append(transaction)
        member.borrowed_books.append(book)
        
        return f"Book borrowed successfully. Due date: {transaction.due_date.date()}"
    
    def return_book(self, isbn, member_id):
        book = self.books.get(isbn)
        member = self.members.get(member_id)
        
        if book in member.borrowed_books:
            book.available_copies += 1
            member.borrowed_books.remove(book)
            
            for trans in self.transactions:
                if trans.book == book and trans.member == member and not trans.return_date:
                    trans.return_date = datetime.now()
                    fine = trans.calculate_fine()
                    if fine > 0:
                        return f"Book returned. Fine: ${fine}"
                    return "Book returned successfully"
        
        return "Transaction not found"

# Usage Example
library = Library("City Library")

class Product:
    def __init__(self, product_id, name, price, stock):
        self.product_id = product_id
        self.name = name
        self.price = price
        self.stock = stock
    
    def update_stock(self, quantity):
        self.stock += quantity
    
    def __str__(self):
        return f"{self.name} - ${self.price} ({self.stock} in stock)"

class CartItem:
    def __init__(self, product, quantity):
        self.product = product
        self.quantity = quantity
    
    def get_subtotal(self):
        return self.product.price * self.quantity

class ShoppingCart:
    def __init__(self):
        self.items = []
    
    def add_item(self, product, quantity):
        if product.stock >= quantity:
            self.items.append(CartItem(product, quantity))
            return f"Added {quantity} x {product.name}"
        return "Insufficient stock"
    
    def remove_item(self, product_id):
        self.items = [item for item in self.items 
                     if item.product.product_id != product_id]
    
    def get_total(self):
        return sum(item.get_subtotal() for item in self.items)
    
    def display_cart(self):
        print("\n=== Shopping Cart ===")
        for item in self.items:
            print(f"{item.product.name} x {item.quantity} = ${item.get_subtotal():.2f}")
        print(f"Total: ${self.get_total():.2f}")
        print("=" * 30)

class Customer:
    def __init__(self, customer_id, name, email):
        self.customer_id = customer_id
        self.name = name
        self.email = email
        self.cart = ShoppingCart()
        self.orders = []
    
    def place_order(self):
        if not self.cart.items:
            return "Cart is empty"
        
        order = Order(self, self.cart.items[:])
        self.orders.append(order)
        
        # Update stock
        for item in self.cart.items:
            item.product.update_stock(-item.quantity)
        
        self.cart.items = []
        return f"Order placed successfully. Order ID: {order.order_id}"

class Order:
    order_counter = 1000
    
    def __init__(self, customer, items):
        Order.order_counter += 1
        self.order_id = Order.order_counter
        self.customer = customer
        self.items = items
        self.status = "Pending"
        self.total = sum(item.get_subtotal() for item in items)
    
    def update_status(self, status):
        self.status = status
        print(f"Order {self.order_id} status: {status}")

✅ Solution: Password Class

class Password:
    def __init__(self, password):
        self.__password = password  # Private
        self.__attempts = 0
        self.__max_attempts = 3
    
    def verify(self, input_password):
        if self.__attempts >= self.__max_attempts:
            return "🔒 Account locked! Too many failed attempts."
        
        if input_password == self.__password:
            self.__attempts = 0  # Reset on success
            return "✓ Password verified successfully!"
        else:
            self.__attempts += 1
            remaining = self.__max_attempts - self.__attempts
            if remaining > 0:
                return f"✗ Incorrect password. {remaining} attempts remaining."
            else:
                return "✗ Account locked! Too many failed attempts."
    
    def change_password(self, old_password, new_password):
        if old_password == self.__password:
            if len(new_password) >= 8:
                self.__password = new_password
                self.__attempts = 0
                return "✓ Password changed successfully!"
            else:
                return "✗ New password must be at least 8 characters."
        else:
            return "✗ Incorrect old password."
    
    def reset_attempts(self, admin_code):
        if admin_code == "ADMIN123":
            self.__attempts = 0
            return "✓ Attempts reset by admin."
        return "✗ Invalid admin code."

import math

class Shape:
    def __init__(self, name):
        self.name = name
    
    def area(self):
        raise NotImplementedError("Subclass must implement area()")
    
    def perimeter(self):
        raise NotImplementedError("Subclass must implement perimeter()")
    
    def display_info(self):
        print(f"\n{self.name}")
        print(f"Area: {self.area():.2f}")
        print(f"Perimeter: {self.perimeter():.2f}")

class Polygon(Shape):
    def __init__(self, name, sides):
        super().__init__(name)
        self.sides = sides

class Triangle(Polygon):
    def __init__(self, base, height, side1, side2, side3):
        super().__init__("Triangle", 3)
        self.base = base
        self.height = height
        self.side1 = side1
        self.side2 = side2
        self.side3 = side3
    
    def area(self):
        return 0.5 * self.base * self.height
    
    def perimeter(self):
        return self.side1 + self.side2 + self.side3

class Rectangle(Polygon):
    def __init__(self, length, width):
        super().__init__("Rectangle", 4)
        self.length = length
        self.width = width
    
    def area(self):
        return self.length * self.width
    
    def perimeter(self):
        return 2 * (self.length + self.width)

class Circle(Shape):
    def __init__(self, radius):
        super().__init__("Circle")
        self.radius = radius
    
    def area(self):
        return math.pi * self.radius ** 2
    
    def perimeter(self):
        return 2 * math.pi * self.radius

# Test
shapes = [
    Triangle(6, 4, 5, 5, 6),
    Rectangle(5, 3),
    Circle(5)
]

for shape in shapes:
    shape.display_info()

✅ Solution: ComplexNumber with Operator Overloading

import math

class ComplexNumber:
    def __init__(self, real, imaginary):
        self.real = real
        self.imaginary = imaginary
    
    def __str__(self):
        if self.imaginary >= 0:
            return f"{self.real} + {self.imaginary}i"
        else:
            return f"{self.real} - {abs(self.imaginary)}i"
    
    def __add__(self, other):
        return ComplexNumber(
            self.real + other.real,
            self.imaginary + other.imaginary
        )
    
    def __sub__(self, other):
        return ComplexNumber(
            self.real - other.real,
            self.imaginary - other.imaginary
        )
    
    def __mul__(self, other):
        # (a + bi) * (c + di) = (ac - bd) + (ad + bc)i
        real = self.real * other.real - self.imaginary * other.imaginary
        imag = self.real * other.imaginary + self.imaginary * other.real
        return ComplexNumber(real, imag)
    
    def __eq__(self, other):
        return (self.real == other.real and 
                self.imaginary == other.imaginary)
    
    def __abs__(self):
        return math.sqrt(self.real**2 + self.imaginary**2)
    
    def conjugate(self):
        return ComplexNumber(self.real, -self.imaginary)

# Test
z1 = ComplexNumber(3, 4)
z2 = ComplexNumber(1, 2)

print(f"z1 = {z1}")
print(f"z2 = {z2}")
print(f"z1 + z2 = {z1 + z2}")
print(f"z1 - z2 = {z1 - z2}")
print(f"z1 * z2 = {z1 * z2}")
print(f"|z1| = {abs(z1):.2f}")
print(f"z1* = {z1.conjugate()}")

10. Common Interview Questions

🎯 Top 15 OOP Interview Questions

1. What are the four pillars of OOP?

Answer: Encapsulation, Inheritance, Polymorphism, and Abstraction.

2. Difference between __init__ and __new__?

Answer: __new__ creates the instance (called first), __init__ initializes it (called second). __new__ returns the instance, __init__ doesn't return anything.

3. What is MRO (Method Resolution Order)?

Answer: The order in which Python looks for methods in a hierarchy of classes, especially with multiple inheritance. Use ClassName.__mro__ or ClassName.mro() to view it.

4. Explain composition vs inheritance.

Answer: Inheritance is "is-a" relationship (Dog is-a Animal). Composition is "has-a" relationship (Car has-a Engine). Favor composition for flexibility and loose coupling.

5. What are abstract classes?

Answer: Classes that cannot be instantiated and may contain abstract methods that must be implemented by subclasses. Use the ABC module and @abstractmethod decorator.

6. How does Python implement encapsulation?

Answer: Using naming conventions: public (no prefix), protected (_prefix), private (__prefix with name mangling).

7. Class variables vs instance variables?

Answer: Class variables are shared by all instances (defined in class body). Instance variables are unique to each object (defined in __init__ with self).

8. What is duck typing?

Answer: "If it walks like a duck and quacks like a duck, it's a duck." Python doesn't check types, just whether objects have required methods/attributes.

9. Name 5 magic methods.

Answer: __init__, __str__, __repr__, __add__, __len__, __eq__, __getitem__, __iter__, __call__, __enter__

10. What is the difference between @classmethod and @staticmethod?

Answer: @classmethod receives the class as first argument (cls) and can access/modify class state. @staticmethod doesn't receive class or instance, just a utility function grouped with the class.

11. What is method overriding?

Answer: When a child class provides a different implementation of a method that exists in the parent class.

12. What is super() used for?

Answer: To call methods from parent class, especially useful in __init__ to initialize parent class attributes.

13. What is the difference between __str__ and __repr__?

Answer: __str__ is for end-users (readable), __repr__ is for developers (unambiguous, ideally recreatable).

14. Can you have private methods in Python?

Answer: Yes, using double underscore prefix (__method). Python applies name mangling to make them harder to access from outside.

15. What are properties and why use them?

Answer: Properties allow you to use getter/setter methods while maintaining attribute-like syntax. They provide validation, computed values, and encapsulation while keeping clean syntax.

11. Best Practices

🌟 SOLID Principles

  1. Single Responsibility: A class should have one reason to change
  2. Open/Closed: Open for extension, closed for modification
  3. Liskov Substitution: Subclasses should be substitutable for base classes
  4. Interface Segregation: Many specific interfaces better than one general
  5. Dependency Inversion: Depend on abstractions, not concretions

✨ General Best Practices

  • Use meaningful class and method names
  • Keep classes focused and cohesive (Single Responsibility)
  • Favor composition over inheritance
  • Use properties for computed attributes
  • Document classes with docstrings
  • Follow PEP 8 naming conventions
  • Use type hints for clarity (Python 3.5+)
  • Write unit tests for classes
  • Keep methods short and focused
  • Use abstract base classes for interfaces
  • Avoid deep inheritance hierarchies
  • Make attributes private when appropriate
